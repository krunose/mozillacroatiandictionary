Short Description
=================
Croatian spell-check dictionary for Mozilla Firefox, Thunderbird and SeaMonkey with lexical content from the [krunose/hunspell-hr](https://github.com/krunose/hunspell-hr) repository. For more information, please visit [Mozilla Add-ons][mozilla-add-ons].

[hr-hunspell]: https://github.com/krunose/hr-hunspell
[mozilla-add-ons]: https://addons.mozilla.org/en-US/firefox/addon/croatian-dictionary/
